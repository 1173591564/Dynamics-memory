# 第 5 批：来源 id 与正文是否一致

基点是第 4 批。本批只拒绝“id 真实、正文没有依据”的提议和被动候选。不引入模型蕴含判断，不改 eval 评分，不改 `agent/`。

## 决策账本

| 问题 | 选择与理由 | 放弃的方案 | 受影响调用方 | 选错后的失败模式 | 验证 |
|---|---|---|---|---|---|
| 怎样算正文有依据 | 汉字片段在去掉空白后核对：连续两个汉字出现在所引原文即可。ASCII/数字标识按原文切分（空白和标点断开），长度 ≥ 4 的任一标识出现即可。长度 ≥ 8 的标识（不含脱敏占位 `REDACTED`）必须全部出现 | 全文相等（正当释义全部失败）；先去空白再切标识（会把 `handler.ts cannot` 粘成假长标识）；用 LLM 判断蕴含 | `/propose`、被动 candgen 入库 | 编造正文带着真 unit id 入库，或正当释义被假标识规则拒绝 | 引用“q/a”写“部署在 B”被拒；引用含 `8080` 的句子被接受；`handler.ts cannot …` 不被假长标识拒绝 |
| 空结果与错误 | 无依据是该条 `rejected: ungrounded_content`，HTTP 仍 200。不是 500，也不是合法空候选 | 整批 400，或当成成功写入 | 提议批次 | 一条坏提议毁掉同批好提议，或失败被显示成已写入 | 同批一条有依据、一条无依据，只写入前者 |
| 被动 candgen 的来源 | 模型给的 `source_unit_ids` 继续忽略，依据只可能是当前窗口。无依据的候选不入库，计 `n_ungrounded`，不因此再发 `extract_due` | 把无依据候选当成抽取失败并自动重排队（模型一直编造时会热循环）；照单入库 | `observe` 的候选应用 | 窗口里没有的句子被记成该 unit 的记忆 | 模型返回 `source_unit_ids:[999]` 且正文不在窗口：无记忆，src 不会是 999。正文在窗口：src 仍是窗口 id |
| 调查员“看过才可引用” | 本批不强制。应用发生在预算关闭之后，假调查员也不走工具。强制会把内容已核对的直接提议全部拒绝，又无法用现有证据证明看过 | 空 seen 集合一律拒绝 | `AgentWorker` | 修复回路全部拒绝，或没看过的 id 仍能引用 | 不把这项写成已完成。剩余风险写在文末 |
| 旧记忆 | 不回扫历史 `Memory.src`。新写入才校验。已入库的无依据记忆不会被本批删除 | 启动时删除对不上的记忆（不可逆，且旧释义可能被误删） | 启动 | 升级丢掉已有记忆 | 旧 checkpoint 能开，旧记忆还在 |

## 不变量

1. 所引单元存在，但正文没有任何可核对片段出现在这些单元里，则该条不入库。维护点：`_validate_proposal`。故障测试：真 id + 无关正文。
2. 长度 ≥ 8 的非脱敏标识必须出现在所引原文中，否则整条拒绝。维护点：`_content_grounded`。故障测试：真汉字片段 + 假长标识。
3. 被动候选的 src 只能是当前窗口；窗口原文不包含该候选时不创建记忆。维护点：`_process_unit`。故障测试：模型声称 source 999。

## 自查（不是独立审查）

| 目标 | 实现 | 测试 | 剩余风险 |
|---|---|---|---|
| 真 unit id 不能给无关正文背书 | `_validate_proposal` 在来源存在后调用 `_content_grounded` | `test_existing_source_id_does_not_authenticate_unrelated_text` | 两个常见汉字碰巧重合仍会通过 |
| 假的长标识不能夹在真片段里 | 长度 ≥ 8 的非 `REDACTED` 标识必须全部出现在原文 | `test_long_identifier_cannot_ride_on_a_real_span` | 7 个字符的假标识仍可能通过 |
| 被动候选不能自报来源 | `_process_unit` 只对照当前窗口原文；对不上则 `n_ungrounded`，不入库、不重排队 | `test_ungrounded_candgen_is_not_stored_as_window_memory` | 模型复述窗口里的句子仍会入库，这是预期 |

## 剩余风险

两个汉字的常见片段可能让无关句子碰巧通过。这不是蕴含证明。调查员是否真的调用过 log 工具，本批没有持久化的“看过”集合，不能假装已经强制。旧快照没有 `n_ungrounded` 时按 0 打开；把程序退回不认识该计数器的版本后，新快照会加载失败，不会静默丢掉记忆。
